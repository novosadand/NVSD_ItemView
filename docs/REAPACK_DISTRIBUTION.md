# ReaPack Distribution Guide

Research notes for distributing NVSD_ItemView via ReaPack.

## What is ReaPack?

ReaPack is the standard package manager for REAPER scripts and extensions. Users add repository URLs to ReaPack, which then handles downloading, updating, and managing scripts.

## reapack-index Tool

`reapack-index` is a command-line tool that generates the `index.xml` file ReaPack needs. It scans your git repository and creates package metadata from your script files.

**Source:** https://github.com/cfillion/reapack-index/wiki

### Installation

**Windows:**
1. Install Ruby 2.4+ via RubyInstaller (include MSYS2)
2. Install CMake
3. Run: `gem install reapack-index`

**macOS:**
```bash
brew install ruby cmake pkg-config
gem install reapack-index
```

**Linux:**
```bash
# Install ruby-dev, cmake, pkg-config, libssl-dev
gem install reapack-index
```

### Basic Commands

```bash
# Validate packages
reapack-index --check

# Create index.xml (first time)
reapack-index --name 'NVSD_ItemView'

# Update index after commits
reapack-index

# Re-scan specific commit
reapack-index --scan HEAD

# Amend released version (fix mistakes)
reapack-index --amend
```

## Package Metadata

**Source:** https://github.com/cfillion/reapack-index/wiki/Packaging-Documentation

### Required Structure

- Scripts must be in subdirectories (used as categories)
- Root-level files are NOT indexed
- Metadata goes in script header comments

### Metadata Tags

Add these to the top of your main script file:

```lua
-- @description NVSD ItemView - Ableton-style Clip View
-- @author NVSD
-- @version 1.0.0
-- @changelog
--   Initial release
-- @about
--   Ableton-style clip view for REAPER audio items.
--   See source waveform, drag markers to control playback region.
-- @link https://github.com/YOUR_USERNAME/NVSD_ItemView
-- @donation https://gumroad.com/YOUR_PRODUCT
-- @provides
--   [main] NVSD_ItemView.lua
--   [nomain] lib/*.lua
--   [nomain] NVSD_ItemView_Settings.lua
```

### Key Tags

| Tag | Required | Purpose |
|-----|----------|---------|
| `@version` | Yes | Must contain at least 1 digit (e.g., `1.0`, `1.2pre3`) |
| `@description` | No | Display name in ReaPack browser |
| `@author` | No | Creator name |
| `@about` | No | Markdown documentation |
| `@changelog` | No | Version history |
| `@link` | No | Website/forum URLs |
| `@donation` | No | Support links |
| `@provides` | No | Additional files to include |

### @provides Options

```lua
-- Include files in specific sections of REAPER's action list:
-- @provides
--   [main] NVSD_ItemView.lua           -- Shows in Actions
--   [nomain] lib/*.lua                 -- Support files, no action
--   [nomain] NVSD_ItemView_Settings.lua
```

**Platform filters:** `darwin`, `linux`, `windows`, `darwin64`, `win64`, `linux-aarch64`

**Action list sections:** `main` (default), `main=midi_editor`, `nomain`

### Version Format

Versions are NOT decimal numbers. These are valid:
- `1.0`
- `1.0.0`
- `1.2pre3`
- `0.2024-01-15`

Comparison is segment-by-segment, so `1.10` > `1.9`.

## Repository Setup

### Directory Structure for ReaPack

```
NVSD_ItemView/
├── index.xml                    # Generated by reapack-index
├── Scripts/
│   └── NVSD/                    # Category folder
│       ├── NVSD_ItemView.lua    # Main script with metadata
│       ├── NVSD_ItemView_Settings.lua
│       └── lib/
│           ├── config.lua
│           ├── state.lua
│           ├── utils.lua
│           ├── drawing.lua
│           ├── controls.lua
│           ├── settings.lua
│           └── settings_ui.lua
```

### Workflow

1. **Structure repo** - Put scripts in category subdirectory
2. **Add metadata** - Add `@version`, `@description`, etc. to main script
3. **Generate index** - Run `reapack-index --name 'NVSD_ItemView'`
4. **Commit index.xml** - Push to GitHub
5. **Share URL** - Users add `https://github.com/USER/REPO/raw/master/index.xml`

### Updating

After making changes:
1. Update `@version` in script
2. Add `@changelog` entry
3. Commit changes
4. Run `reapack-index`
5. Commit updated index.xml
6. Push to GitHub

## Distribution Strategy

1. **GitHub repository** - Host code and index.xml
2. **Gumroad product** - Include the ReaPack index URL in the product content
3. **Users** - Add the index URL to ReaPack sources, get automatic updates
