NVSD ItemView - Installation Guide
===================================

REQUIREMENTS
------------
- REAPER 6.0 or higher
- ReaPack (package manager)
- ReaImGui extension (required, installed via ReaPack)
- SWS Extension (recommended)
- js_ReaScriptAPI (optional)


STEP 1: Install ReaPack (if you don't have it)
-----------------------------------------------
1. Download from: https://reapack.com
2. Run installer, restart REAPER


STEP 2: Install SWS Extension (Recommended)
-------------------------------------------
Enables: edge-drag waveform display, reverse detection

1. Download from: https://www.sws-extension.org
2. Run the installer
3. Restart REAPER


STEP 3: Add NVSD Repository
----------------------------
1. In REAPER: Extensions > ReaPack > Import repositories
2. Paste: https://raw.githubusercontent.com/novosadand/NVSD_ItemView/master/index.xml
3. Click OK


STEP 4: Install the Script
--------------------------
1. Extensions > ReaPack > Browse packages
2. Search for "NVSD ItemView"
3. Right-click > Install
4. Restart REAPER
5. The script is now in your Actions list!

Note: You also need to install ReaImGui via ReaPack (search "ReaImGui" in Browse packages).


STEP 5: (Optional) Assign a Shortcut
------------------------------------
1. In the Actions List, search for "NVSD ItemView"
2. Click "Add..." to assign a keyboard shortcut
3. Or right-click > "Add to toolbar"


MANUAL INSTALLATION (without ReaPack)
--------------------------------------
If you downloaded the ZIP from Gumroad:

1. Extract the ZIP contents
2. Copy the entire folder to your REAPER Scripts directory:
   - Windows: %APPDATA%\REAPER\Scripts\NVSD\
   - macOS: ~/Library/Application Support/REAPER/Scripts/NVSD/
   - Linux: ~/.config/REAPER/Scripts/NVSD/
3. In REAPER: Actions > Show action list
4. Click "Load ReaScript..."
5. Navigate to the folder and select "NVSD_ItemView.lua"
6. The script now appears in your Actions list
7. Optionally assign a keyboard shortcut or add to toolbar

Note: You still need ReaImGui installed (available via ReaPack).


USAGE
-----
1. Select an audio item in REAPER
2. Run the script (via shortcut, toolbar, or Actions List)
3. The ItemView window opens showing your full audio source
4. Drag blue markers to adjust which portion plays
5. Use left panel for gain, pitch, and warp controls

For full documentation, see README.md


UPDATING
--------
Extensions > ReaPack > Synchronize packages
Updates are delivered automatically.


TROUBLESHOOTING
---------------
"This script requires ReaImGui" error:
  -> Install ReaImGui via ReaPack and restart REAPER

Window doesn't appear:
  -> Make sure ReaImGui is installed and REAPER was restarted

Waveform doesn't show when dragging item edges:
  -> Install SWS Extension for this feature
