NVSD ItemView - Installation Guide
===================================

REQUIREMENTS
------------
- REAPER 6.0 or higher
- ReaImGui extension (required)
- SWS Extension (recommended)
- js_ReaScriptAPI (optional)


STEP 1: Install ReaImGui (Required)
-----------------------------------
1. Open REAPER
2. Go to: Extensions > ReaPack > Browse packages
3. Search for "ReaImGui"
4. Right-click > Install
5. Restart REAPER

If you don't have ReaPack:
- Download from: https://reapack.com
- Run installer, restart REAPER, then follow steps above


STEP 2: Install SWS Extension (Recommended)
-------------------------------------------
Enables: edge-drag waveform display, reverse detection

1. Download from: https://www.sws-extension.org
2. Run the installer
3. Restart REAPER


STEP 3: Install the Script
--------------------------
1. Open REAPER
2. Go to: Options > Show REAPER resource path in explorer/finder
3. Open the "Scripts" folder (create it if it doesn't exist)
4. Copy "NVSD_ItemView.lua" into the Scripts folder


STEP 4: Load the Script
-----------------------
1. In REAPER, open the Actions List (press "?" or go to Actions > Show action list)
2. Click "Load ReaScript..."
3. Navigate to your Scripts folder
4. Select "NVSD_ItemView.lua"
5. The script is now in your action list!


STEP 5: (Optional) Assign a Shortcut
------------------------------------
1. In the Actions List, find "Script: NVSD_ItemView.lua"
2. Click "Add..." to assign a keyboard shortcut
3. Or right-click > "Add to toolbar"


USAGE
-----
1. Select an audio item in REAPER
2. Run the script (via shortcut, toolbar, or Actions List)
3. The ItemView window opens showing your full audio source
4. Drag blue markers to adjust which portion plays
5. Use left panel for gain, pitch, and warp controls

For full documentation, see README.md or visit the product page.


TROUBLESHOOTING
---------------
"This script requires ReaImGui" error:
  → Install ReaImGui via ReaPack and restart REAPER

Window doesn't appear:
  → Make sure ReaImGui is installed and REAPER was restarted

Waveform doesn't show when dragging item edges:
  → Install SWS Extension for this feature
